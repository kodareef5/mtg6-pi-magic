# Main-deck alpha guides

These 19 guides cover the imported legal Standard lists without sideboards.
`tools/guide.ts --all --alpha` generated them from the pinned card file on
October 11, 2026, using the selected `gpt-6.1-sol:high` pregame role. The run
made 57 provider calls across 19 guide sessions and cost $0.8770.

Both seats' pregame analysts read the guides for the registered decks. A guide
is advice about sequencing and resource use; it does not establish engine
support or certify a card interpretation. The current board, exact card text
and accepted rules decisions take precedence.

The tournament lists in `decks/collection/` retain their sideboards. Fresh
alpha games use `tools/matchup.ts --decks 'A,B' --alpha`; each journal records
the exact sideboardless lists used in that game.
