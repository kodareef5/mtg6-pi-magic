# Examples by shape

Worked uses of the syntax in `docs/SYNTAX.md`, indexed by what they show rather
than by card. Most cards come from Standard outside the matchup, so read them to
learn the shape, then read your own card. Every block parses under the real
schemas, and every `basis` is checked against the card's text.

| File | Shows |
|---|---|
| `spells.md` | targets, any target, destroy, modes as separate procedures, kicker, a token's activated ability |
| `mana.md` | mana abilities in a package, "or", counted mana, spend restrictions, a token's mana ability |
| `entering.md` | entering tapped under a condition, entering with counters, how other permanents enter, 305.7 |
| `triggers.md` | landfall, enters with a target, step beginnings, dies, attacks, cast, reflexive "when you do" |
| `statics.md` | lords, conditional statics, linked exile, Auras and `attached`, fight |
| `until-end-of-turn.md` | temporary changes, counters with keywords, doubling power, `if` and `limit`, play permissions |
| `costs.md` | sacrifice with last known information, discard or exile the card itself, life, reductions |
| `search.md` | searching as choose, move, shuffle, from a land and from a spell |
| `warp.md` | an alternative cost with a delayed exile and a permission to cast again |
| `animation.md` | crew, a land becoming a creature, earthbend, changing creature types and granting a trigger |
| `x-costs.md` | X in a cost, a permanent remembering X, counted X, `sum`, damage to each |
| `stack-and-replacements.md` | countering, ward, a replacement placed by a spell, rules words, `each`, suppression |
| `baseline-overrides.md` | the baseline rules, and the cards that change them: extra lands, haste, flash |
| `turn-plan.md` | a whole turn as a plan, with a reaction, asks, phase guidance and packages |
| `reactions.md` | plans for the opponent's turn |
| `combat.md` | attack and block plans, marked options, damage |
| `asking.md` | when the plan asks for a new one: stops, their windows, the budget |
