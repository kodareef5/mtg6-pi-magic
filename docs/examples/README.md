# Examples by shape

Worked uses of the syntax in `docs/SYNTAX.md`, indexed by what they show rather
than by card. Most cards come from Standard outside the matchup, so read them to
learn the shape, then read your own card. Every block parses under the real
schemas, and every `basis` is checked against the card's text.

| File | Shows |
|---|---|
| `spells.md` | targets, any target, destroy, modes as separate procedures, kicker, a token's activated ability |
| `mana.md` | mana abilities in a package, "or", counted mana, spend restrictions, a token's mana ability, a Verge's conditional ability |
| `entering.md` | entering tapped under a condition, a shock land's optional life payment, a Town's own-turn count, entering with counters, how other permanents enter, 305.7 |
| `triggers.md` | landfall, enters with a target, step beginnings, dies, attacks, cast, reflexive "when you do" |
| `cast-facts.md` | mana-value and color selectors, computed bounds, cast triggers and last known spell facts |
| `payments.md` | blight and behold as additional costs, and optional counter payment during resolution |
| `inspection.md` | bounded private looks, computed library windows, selection and chosen or random bottom order |
| `spell-properties.md` | restriction words on the next matching cast, applied before responses, with expiry if unused |
| `last-known.md` | exile before life changes, using a departed target's former controller |
| `entry-choices.md` | choose a basic land type before entry payment; derive its intrinsic mana ability |
| `damage.md` | damage sources, recipients and amounts; starting life; an optional effect used once each turn |
| `casting-permissions.md` | alternative and printed prices, spell filters, stack departure replacements, exiled ownership, permission through the next turn and firebending mana |
| `statics.md` | lords, conditional statics, linked exile, Auras and `attached`, fight |
